代码作业助手 课程学习

完成课程作业、逐行讲解看不懂的代码

▾

用来做什么

  • 把课程发下来的 作业压缩包（作业二.zip） 解压后，按题目要求补全里面的 Python 代码
  • 对已经写出来但看不懂的代码逐行解释，比如 prime_set = set(primes) 为什么要转成集合
  • 解释基础但容易混的语法点：strip() 到底去掉什么、eval() 是干什么用的
  • 把课本或老师图里的代码照着复现成可运行文件

得到什么

  • 作业从「卡住」到能跑通、能交上去
  • 不只是拿到答案，还看懂了为什么这么写
  • 攒下一批自己写的、能直接复用的代码片段
当时下的指令 @作业二.zip 完成压缩包中编写代码的任务  ·  4_10.py 中 strip() 的作用
✅

作业自检助手 课程学习

拿「要求文件」逐条对照检查自己的作业

▾

用来做什么

  • 把作业要求（文件二）和我的提交（文件一）一起交给它，让它逐条比对
  • 输出一份检查报告：符合 / 部分符合 / 不符合，并标注具体行号
  • 改完之后再让它复查一遍，确认之前的扣分点是否真的修好了
  • 比较两个压缩包的内容，确认哪个版本才满足要求

得到什么

  • 提交前就发现了一处量纲错误（20 % V 应为 20000 / V）
  • 用 4 组测试数据逐一验算，输出与手工计算完全吻合
  • 养成「交之前先自检一遍」的习惯
当时下的指令 以「文件二」中的要求作为验收标准，逐条检查「文件一」的实现是否合规
💡

编程答疑助手 课程学习

课后补概念、解经典例题

▾

用来做什么

  • 问基础概念：Python 里怎么实现矩阵转置，要几种不同写法并对比
  • 解经典例题：用 for 循环解「百钱百鸡」，要求说清变量设计和运行流程
  • 搞懂小技巧：列表分块打印 for n in range(0,len(lst),5) 是怎么工作的

得到什么

  • 矩阵转置一次拿到 3 种写法（zip(*m)、列表推导、NumPy），知道各自适用场景
  • 百钱百鸡从「暴力枚举 20 万次」优化到数学推导 O(1) 求解，理解了循环剪枝
  • 课堂上没听懂的细节，课后自己补上了
当时下的指令 python 中怎么实现矩阵的转置  ·  python for 循环解决百钱百鸡问题

演示文稿助手 课程学习

做小组汇报 PPT、把 PDF 转成可编辑幻灯片

▾

用来做什么

  • 按给定的排版要求，联网搜集一个地方的资料并做成 PPTX
  • 给已经做好的 PPT，在介绍页里补上真实的实景照片，而不是随便找的素材图
  • 把一份样张 PDF 转成可编辑的 PPT，方便继续改

得到什么

  • 一份完整的汇报 PPT，7 张配图全部可溯源（政府官网、央广网等公开页面）
  • 配图是逐张核对页面文字说明确认的，没有凭文件名猜
  • 省下了大量「找图 + 排版」的时间
当时下的指令 联网搜索江苏省连云港市灌南县的相关资料并以此制作符合图片要求的 pptx 文件

资源检索助手 技能探索

找教材配套资源、找公开课件

▾

用来做什么

  • 学会了「先找官方渠道」这个检索习惯
当时下的指令 在 github 上找到这本书的 PDF 版，文件放在桌面上  ·  找找这本书公开的教学课件

05 写在最后

它们没有替我学习，是帮我把时间花在了该花的地方

刚上大学的时候，我经常在「不知道从哪下手」这件事上耗掉整个晚上 —— 一份作业翻来覆去看不懂要求， 一个报错查半天也找不到原因。这些 Agent 最先帮我的，其实是把这种「卡住」的状态缩短了。

但用到现在，我慢慢明白一件事：如果只是让它把答案给我，那作业交上去我也还是不会。 所以后来我改了个用法 —— 让它讲清楚为什么，我自己再动手写一遍、跑一遍。 检查报告里那处量纲错误，是我自己看懂了之后改的；百钱百鸡的优化思路，也是我照着推导又推了一遍才记住的。

这份记录里最值得留下的，不是「用了几个 Agent」，而是这几个月里我确实把一些原来不会的东西， 变成了自己会的东西。工具会一直换，但是这个习惯我想留下来。
